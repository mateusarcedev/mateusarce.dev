# Security Policy

## Supported version

The actively maintained version is the code currently published from the `main` branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability.

Send the report to **contato@mateusarce.dev** with the subject **[SECURITY] mateusarce.dev** and include:

- a clear description of the issue;
- affected route, component or dependency;
- reproduction steps or proof of concept when available;
- expected impact;
- any suggested mitigation.

Do not include credentials, private tokens or unrelated personal data in the report.

I will review reproducible reports and address confirmed issues according to their severity.
